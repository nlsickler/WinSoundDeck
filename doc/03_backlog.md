# Backlog

WinSoundDeck's feature backlog and triage now live in **[GitHub Issues](https://github.com/nlsickler/WinSoundDeck/issues)** using MoSCoW priority labels:

- **`Must Have`** — Required for the next milestone
- **`Should Have`** — High-value usability improvements
- **`Could Have`** — Nice-to-have additions if there is interest
- **`Won't Have`** — Intentionally out of scope (closed as *not planned* for transparency)
